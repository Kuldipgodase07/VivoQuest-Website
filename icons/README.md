# VivoQuest Central Asset & Icon Registry

This directory contains the production visual assets for the VivoQuest Web App, categorized strictly by product domain.

## Subfolder Mapping

| Directory | Description | Primary Format |
|---|---|---|
| `banners/` | Hero banners for service pages (Home Visit, Rehab, Diagnostics, Adult Care) | PNG, JPG |
| `brand-logos/` | Official VivoQuest logo marks, checkmarks, trust badges | PNG, SVG |
| `home-diagnostics/` | Diagnostic equipment, tests (ECG, Holter, X-Ray, Blood, Vitals) | SVG, PNG |
| `home-visit/` | In-home doctor visits, nursing procedures, therapies, consultations | SVG |
| `landing-page/` | Hero transparent cutout, category icons, wellness packages | SVG, PNG, JPG |
| `long-term-care/` | ICU at home, mother & baby, senior care, nurse attendant | SVG |
| `rehab-services/` | Cardiac, neuro, oncology, ortho, palliative, stroke, transplant rehab | SVG |

## Design Guidelines & Conventions
- **Scalable Vector Graphics (SVG)**: Optimized via SVGO with `viewBox="0 0 24 24"` or standard responsive aspect ratios.
- **Teal & Indigo Palette**: Primary brand colors `#4520B8` (VivoQuest Indigo) and `#0D7A5F` (Teal), with `#F7F5FF` background tint.
- **Naming Convention**: Clean lowercase hyphenated (`kebab-case`), e.g., `doctor-at-home.svg`.
